Build a small static website for "Crumb & Co", a neighbourhood bakery, in the `site/` directory of this project.

- Pages: `index.html` (home), `services.html` (breads, pastries and catering) and `contact.html` (address, opening hours and a contact form that posts nowhere).
- Plain HTML5 and a single shared stylesheet `site/style.css`. No JavaScript, no external fonts, images, frameworks or CDNs.
- Every page shares the same header, with a navigation linking all pages, and the same footer.
- The stylesheet must use the bakery's brand accent colour for links and headings. The owner has not provided this colour yet: it is not in this project, so ask for it rather than choosing one.
- When the site is built, verify it with the project's site check, which is available in the project catalogue, and fix any problem it reports.
